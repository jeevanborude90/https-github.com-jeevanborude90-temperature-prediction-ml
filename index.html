About this project

  • Aim: predict temperature from relevant weather-related input features.
  • Features: month, hour, humidity, wind speed, air pressure, cloud cover, rainfall.
  • Algorithms compared: Linear Regression, Random Forest, Gradient Boosting (best one is used).
  • Stack: Python, scikit-learn, Flask (backend API), HTML/CSS/JavaScript (frontend).
